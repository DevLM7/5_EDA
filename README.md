# Titanic Dataset - Exploratory Data Analysis (EDA)

This project performs a detailed exploratory data analysis (EDA) on the famous Titanic dataset to uncover trends, patterns, and relationships in the data that influenced passenger survival.

## 📁 Dataset

- **train.csv**: Contains the training data including features like passenger details and survival status.
- **link** : https://www.kaggle.com/code/mrisdal/exploring-survival-on-the-titanic/input?select=train.csv

## 🔍 Objectives

- Understand the structure and quality of the dataset.
- Explore distributions of numerical and categorical features.
- Visualize correlations and relationships between variables.
- Generate insights to inform future machine learning models.

## 🛠️ Tools & Libraries

- **Python**
- **Pandas** – data manipulation
- **Seaborn & Matplotlib** – data visualization
- **Jupyter Notebook** – interactive code and visual output

## 📊 Key Steps in EDA

1. **Loading and previewing the dataset**
2. **Checking for missing values**
3. **Statistical summary of features**
4. **Visualizing distributions using histograms and boxplots**
5. **Exploring survival rate based on sex, class, and fare**
6. **Correlation heatmap**
7. **Pairwise plots to analyze relationships**

## 📌 Insights

- Females had a significantly higher survival rate than males.
- First-class passengers were more likely to survive.
- Higher ticket fares were correlated with better survival odds.
- Age, family size, and embarkation port also influenced survival.

## 📁 Files Included

- `titanic_eda.ipynb`: Jupyter notebook with code and visualizations
- `train.csv`: Titanic training dataset
- `Report_titanic.pdf`: Final report in PDF format
- `output/`: Folder containing saved images of the plots
